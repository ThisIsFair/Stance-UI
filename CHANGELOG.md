# Changelog

## 0.1.0 — Initial beta release

- Standalone Matcha `Drawing` UI core and pooled rendering
- Reusable multiple windows, sidebar tabs, collapsible sections
- Buttons, toggles, sliders, single/multiple dropdowns, textboxes, keybinds, RGB color pickers, labels, paragraphs and dividers
- Four built-in themes, custom themes and accent overrides
- Basic toast notifications and confirmation dialog
- Mouse/keyboard input routing, input capture, resize/drag, hotkeys, scrolling
- JSON-based local configuration storage and unloading/cleanup
- Documentation, demo, and mocked-runtime smoke test

**QA status:** Lua syntax and mocked-runtime smoke tests passed. In-game rendering not yet verified.
